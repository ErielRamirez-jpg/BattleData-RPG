# Pokémon Game - Proyecto Estructuras de Datos

## Ejecutar
```bash
npm install
npx expo start
```

## Incluye
- 6 estructuras de datos implementadas a mano
- Sprites front/back/icon de 6 criaturas
- Iconos de ítems
- Fondo de batalla (bosque)
- Componente BarraHP
- Batalla, Mochila, Mapa (BFS), Pokédex (Hash)
